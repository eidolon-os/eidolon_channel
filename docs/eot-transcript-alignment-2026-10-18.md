# EOT 与 ASR 候选对齐修复

日期：2026-10-18。对比基线：Channel `aa86d2d`。范围：Channel 内的候选生命周期及提交边界；不涉及 Agent 历史、业务请求完整性判断、模型替换或生产发布。

## 修复对象与实现

此前可复现的链路是：用户说“嗯，那个……”后继续说天气请求，Channel 在停顿超过 800 ms 后替换了尚未提交的候选，framework 却仍保留旧前缀。音频 EOT 比天气 ASR final 更早返回，旧前缀被用于新候选，发生缺字或倒序拼接。两个 host 都复现，不能靠给 Pi5 换模型解决。

本次修改四个行为实现文件，并同步配置注释；继续使用现有候选、证据通知和唯一提交入口：

| 边界 | 本次行为 | 保留的原行为 |
|---|---|---|
| `UserTurnCoordinator` | 已有转写的 open 候选持续到产品提交或拒绝；停顿本身不丢弃未提交文本 | 无转写候选仍受原声学 grace 约束；已提交或拒绝的轮次不合并后续发言 |
| 转写就绪检查 | 续说前最新 ASR revision 已结束、续说尚无转写时，等待已有通知；旧前缀不直接证明续说文本已就绪 | 同一未结束 provider revision 可跨 VAD 片段；合法 interim 提交继续可用 |
| `TranscriptSettlementLease` | 等待期间再次开口，使旧完成请求失效；保留候选给新结束证据处理 | 候选替换保护、事件通知、取消清理及既有超时预算 |
| framework 完成入口 | 声纹异步等待复用现有 candidate/generation fence；旧成功、拒绝或异常结果都不能作用于新语音 | 声纹策略、D3 意图裁决和唯一规范文本发布入口 |
| AgentSession 退出 hook | 在 SDK drain 前调用现有生命周期 owner 的候选终止处理，唤醒转写等待；退出后不提交旧候选 | 原有关闭终态记录；SDK 自身的提供商排空及超时逻辑 |

没有新增模型、网络调用、文本分类器、候选容器、调度器、配置项或固定静音等待。D3 仍只提供现有打断意图证据。

主回放、ASR 事件回放和时序对照合计 **92 条**。场景测试分主批和补充批执行，重跑的用例只计一次。主批的 3 个意外失败均是中文片段中间空格的精确字符串断言；内容、顺序、抢话、耗时和单次提交检查都已通过。改为检查完整有序内容后，三个变体全部通过；没有放宽延迟或抢话断言。

关闭回归先在基线复现：Channel 的候选等待未在退出时及时结束。修复后，候选拒绝及等待清理在 1 s 的测试上限内完成，不产生用户提交或助手消息。SDK 自身没有 final 时的排空等待仍保留，独立测试预算为 6 s；不能把这个结果解释成整个关闭过程小于 1 s。

另做 Mac 较大范围对照：基线 **1,466 通过 / 41 失败 / 11 xfail**，最终 **1,482 通过 / 同样 41 失败 / 11 xfail**（两者另有 1 项 deselected）。逐个失败 ID 比较没有新增失败。41 项既有失败分布在 endpointing 测试替身、语义 handler、产品契约和 welcome 测试中，本次没有扩展去修改这些模块，不能宣称仓库全量测试全绿。

两端最终 443 个运行时和测试文件哈希一致。Ruff 与 `git diff --check` 通过。证据见 [最终对照 JSON](../../diagnostics/2026-10-18-eot-alignment-fix/final-comparison.json)、[完整验证目录](../../diagnostics/2026-10-18-eot-alignment-fix/README.md)。

mini 0.20 在最后一项修复前约 3 ms 就提交了错误前缀；现在先等待缺失的转写再提交完整文本。额外记录的 settlement 等待为 **Mac 343.1 / 344.8 ms、Pi5 344.6 / 343.9 ms**（仅 final / 提前 interim），由实际转写到达唤醒，不是人为添加的固定延迟。

其他正常短请求未出现新的固定等待；播放中追问还包含 D3 网络变化，不把单次差值归因于这段代码。mini 默认的完整句迟答及激进阈值的离线误判取舍仍存在，修复文本正确性不等于完成模型升级。


## 判断标准与边界

- 首先检查提交文本是否完整且顺序正确；错误文本的快速提交不计为延迟收益。
- 完整句后长停顿再补充，允许形成两轮。没有用减少提交数作为质量目标。
- 比较等待时间时，使用相同录音、ASR 事件、VAD、EOT 参数与 D3。VAD listening → commit 不是最后音素 → BOX-3 首声。
- 没有 provider 时间戳/身份的输入不能宣称精确音频覆盖。实现利用现有候选、ASR revision 和接收顺序，元数据路径有独立回归；没有伪造时间对齐能力。
- ASR 永不返回时，仍沿用现有有界 deadline fallback，明确记录降级原因；本次不改变这一产品策略，也不把超时当作完整文本已到达。会话退出时 Channel 候选和等待立即终止，但 SDK 仍可能等待其原有 ASR 排空期限；没有声称整个 SDK 关闭都能立即完成。
- 回放使用实际 Channel / AgentSession、真实 VAD/EOT；录制或脚本化 ASR、模拟 LLM/TTS。D3 在播放重叠场景中是真实服务；场景故障注入测试则使用可控意图结果。
- 不包含新的 BOX-3 麦克风、实际停声或真实 Agent 工具验收；不宣称修复了模型分类错误或 ASR 网络故障。

## 当前选择

生产继续保留 **Mac / Pi5：FireRed + D3**。本次修复解决已定位的对齐缺口，不构成 mini 优于 FireRed 的证据。mini 默认完整句迟答、激进阈值在离线片段上的错误取舍，仍应独立评价。后续模型比较复用本次对齐回归，保持单主 EOT；没有依据增加双模型级联或按 host 分叉语义方案。
